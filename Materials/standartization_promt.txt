You are adding a new material model to the standardized thin-film nonlinear-optics pipeline.

Do not invent a new architecture. Convert the material into the existing two-stage convention:

Stage 1:
A material-specific MATLAB script computes standardized band data.

Stage 2:
The universal response calculator computes S_photo, Omega_z_photo, D_photo, and J_photo using the same formulas for every material.

The material-specific script must only handle:
- Hamiltonian definition
- velocity operators
- eigensystem
- Berry curvature
- conversion to standardized band_data units
- diagnostic plots

The universal response formulas must not be duplicated or modified inside the material script.

============================================================
UNIVERSAL SAVED UNITS
============================================================

All saved band_data and response_data must use:

energy   = meV
length   = nm
momentum = nm^{-1}

Therefore:

energy(ix,iy,n)    must be in meV
vx(ix,iy,n)        must be in meV nm
vy(ix,iy,n)        must be in meV nm
Omega(ix,iy,n)     must be in nm^2
kx_grid, ky_grid   must be in nm^{-1}
dk_area            must correspond to nm^{-2}/(2*pi)^2

Native model units may be different, but final saved variables must be converted.

Common conversions:

1 eV = 1000 meV
1 Angstrom = 0.1 nm
1 Angstrom^{-1} = 10 nm^{-1}

If the native model uses eV and Angstrom^{-1}:

E_meV = 1000 * E_eV

k_nm^{-1} = 10 * k_A^{-1}

v_native = dE[eV]/dk[A^{-1}] has units eV Angstrom
v_meV_nm = 100 * v_native

Omega_native has units Angstrom^2
Omega_nm2 = 0.01 * Omega_native

D_native has units Angstrom
D_nm = 0.1 * D_native

If a final J is computed natively in meV Angstrom:
J_meV_nm = 0.1 * J_meV_A

If a final J is computed natively in eV Angstrom:
J_meV_nm = 100 * J_eV_A

Do not save huge eigenvector arrays or full band-basis matrices unless a DEBUG_SAVE_RAW flag is enabled.

============================================================
BERRY CURVATURE CONVENTION
============================================================

For each band n, compute:

Omega_n^{xy}(k) =
    -2 Im sum_{m != n}
        <n|Vx|m><m|Vy|n> / (E_m - E_n)^2

or the algebraically equivalent convention already used in the existing scripts, as long as the same sign convention is documented.

Velocity convention:

v_n^x = <n|dH/dkx|n> = partial_x E_n
v_n^y = <n|dH/dky|n> = partial_y E_n

Saved vx, vy must be in meV nm.

============================================================
STAGE 2: UNIVERSAL RESPONSE FORMULAS
============================================================

Do not duplicate these formulas in the material script. They belong in the universal response calculator.

The universal response calculator must use:

Omega_z(mu) =
    sum_n int_k f_n(k,mu) Omega_n^{xy}(k)

D^i(mu) =
    - sum_n int_k Omega_n^{xy}(k) partial_i f_n(k,mu)

S^{gamma j}(mu) =
    - sum_n int_k f'_n(E) v_n^j v_n^gamma

J^{i j gamma}(mu) =
    - sum_n int_k f'_n(E) v_n^j partial_i v_n^gamma

where:

x = 1, y = 2
S_photo(mu,gamma,j)
D_photo(mu,i)
J_photo(mu,i,j,gamma)

and:

partial_i f = f'(E) v_i

The stored BCD sign is always:

D_photo(:,i) = - int_k Omega_xy partial_i f

Do not allow material-specific sign fixes.

============================================================

============================================================

Each material script should produce lightweight diagnostic plots:

1. Band-structure slice:
   - simple 1D cut, e.g. ky = 0 and kx varying
   - x-axis: k [nm^{-1}]
   - y-axis: E [meV]
   - title should include material name

2. Berry curvature map for one representative band:
   - axes in nm^{-1}
   - colorbar
   - title includes band index

The universal response calculator should produce response plots:

1. D_photo(:,1), D_photo(:,2) versus mu_grid
2. S_photo(:,1,1), S_photo(:,2,2), optionally S_photo(:,1,2)
3. J_photo(:,1,1,1), J_photo(:,2,2,2), optionally J_photo(:,1,1,2)
4. Omega_z_photo versus mu_grid

Labels:

mu [meV]
D [nm]
S [meV]
J [meV nm]
Omega_z dimensionless
